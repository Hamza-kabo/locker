# locker
📌 Project Overview
A Minimum Viable Product (MVP) designed to provide a basic yet functional platform for students to reserve lockers in academic institutions. My role focused on the Software Engineering orchestration, ensuring the microservices communicated effectively and the infrastructure was stable.

🏗 System Architecture
Frontend: React.js (locker-reservation-app)

Backend API: FastAPI / Python (locker-reservation-api)

Database: MongoDB

My Role: Integrated the frontend and backend services, managed the database connection logic, and oversaw the technical deployment of the system.
